# Wildlife Control Index static site

Open `index.html` in a browser. No build step required.

Compiled by **Stephen Shortell**. Unpaid directory. Names transcribed from official lists only.

## Publish on GitHub Pages (free)

1. Public repository; site files at the repo root.
2. Keep `.nojekyll` so GitHub does not run Jekyll.
3. Settings → Pages → Deploy from a branch → `main` → `/` (root).
4. Site: `https://shortelldesigns.github.io/wildlife-control-index/`

Relative links work on a project-pages subpath.
